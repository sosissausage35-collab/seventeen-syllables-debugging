One haiku about debugging, in the 5-7-5 syllable shape, written to `/output/entry.txt`:

> Breakpoint holds its breath
> the log scrolls past, line by line
> one typo did this

A breakpoint waits, the logs scroll on — and the whole chase comes down to a single typo.

## Run it

```sh
node main.ts
```
